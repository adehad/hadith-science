# Translation queries

Places where the translation looks off. The site follows the Arabic term until the owner rules.

| §5.20 | muʿḍil | Term is muʿḍal (passive). See also the §5.20 bracket row below | |
| §5.20 | "[then this is also muʿḍil]", for a single or non-consecutive drop | The Arabic makes a single or non-consecutive drop munqaṭiʿ, not muʿḍal. Confirm the bracket is a slip; the site follows the Arabic (munqaṭiʿ). Term spelling: see the row above | |
| §5.36 majhūl al-ʿayn | accepted if the sole person reporting from him is "an authority" | The Arabic (مُتَأَهِّلًا) likely means the sole narrator himself vouches for him, if he is qualified to. Confirm; the site says "qualified to judge him" | |
| §5.36 mastūr | the majority "rejected this" | Is it his reports, or the stance of accepting them unconditionally, that the majority reject? The site uses neutral wording ("the majority did not") | |
| §5.60 | "the form" | Renders الشَّكْل, which here means vowelling, not letter shape. Confirm; the site says "dots or vowels" | |
| §5.61 | "an extra alif" (ʿAbd Allāh ibn Yazīd vs ibn Zayd) | The added letter is a yāʾ, not an alif. Confirm; the site says "one letter more" | |
| §5.55 | step 2 akhbaranā; plural akhbaranā/qaraʾnā put with quriʾa ʿalayhi; step 1 ḥaddathanā for hearing alone | The plural forms appear where the narrator was alone. Should the scene display the singular forms (أَخْبَرَنِي, حَدَّثَنِي) on steps 1 and 2 instead? | |
| §5.58 | "as Ibn al-Ṣalāḥ states", followed by reasoning | Is the reasoning that follows Ibn al-Ṣalāḥ's or Ibn Ḥajar's own? The site credits Ibn Ḥajar | |
| §5.16.2 (p.159) | "If harmonisation is possible, the preferred is specified. And if not, then it is not." | The context is preference, not harmonisation: it should read "if *preference* is possible, the preferred one is singled out". The site follows the sense (tarjīḥ) with neutral wording ("if a preference can be made, the preferred report is singled out") | |
| §5.13 | Partial follow-up when the agreement is "for his shaykh or whoever is *below* him" | The Arabic is likely فَمَنْ فَوْقَهُ, "whoever is *above* him", towards the Companion; the book's own example joins at Ibn ʿUmar, above al-Shāfiʿī's shaykh. The site uses neutral wording ("with the narrator's teacher, or joins further along the chain") | |
| §5.12 | The reliable narrators recorded it "as being from Abū Isḥāq only [and not up to the Prophet]" | The Arabic is likely مَوْقُوفًا: their version stops at the Companion, Ibn ʿAbbās, not at Abū Isḥāq. The site draws their track from Ibn ʿAbbās and says only that they did not carry it up to the Prophet ﷺ | |
| §5.10.2 | The list of masters includes "Ibn Abī Ḥātim (d. 327/938)" | Paired with Abū Zurʿa, the Arabic likely names Abū Ḥātim al-Rāzī (d. 277), his father. The site leaves him out of that list until a ruling | |
| §5.10 | "Hasan is a report whose [grade of] fairness is because of compensating factors…" | This sentence defines ḥasan *li-ghayrihi*, the kind that "and not by other" excludes, not ḥasan in general. The site treats it so | |
| §5.12 | "Ḥubbayb ibn Ḥabīb" | The usual vocalisation is Ḥubayyib. The site writes Ḥubayyib; confirm | |
| §5.13 | ʿĀṣim ibn Muḥammad, "from his father Muḥammad ibn Zayd, from his grandfather ʿAbd Allāh ibn ʿUmar" | Ibn ʿUmar is Muḥammad ibn Zayd's grandfather, ʿĀṣim's great-grandfather, so "his" refers to the father. The site leaves "grandfather" out | |
